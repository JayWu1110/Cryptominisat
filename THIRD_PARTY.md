# Third-party components

## CryptoMiniSat

This repository redistributes a prebuilt **CryptoMiniSat 5.13.0** binary
(`bin/cryptominisat5`) and related static libraries under `lib/` for
convenience on Linux x86-64.

- Upstream: https://github.com/msoos/cryptominisat
- License: MIT (see upstream repository)
- You may replace these files with another CryptoMiniSat build or install
  from official releases.

The scripts, testcases, and documentation in this repository are separate
works licensed under the MIT License in `LICENSE`.
